# Pilot Offer Template

Use this document as the baseline commercial structure for a paid pilot.

## Offer title

`Enterprise learning workspace pilot`

## Objective

Validate that `Learning Hub` can improve:

- learner completion
- time-to-readiness
- manager visibility
- content governance

## Suggested pilot scope

- `1` business unit or academy
- `100-300` learners
- `2-3` learning tracks
- `1` branded deployment
- `6-8` weeks

## Included capabilities

- public catalog and course discovery
- learner workspace
- guided lesson flow
- recordings and practice
- completion rules and attestation
- admin control plane
- manager/compliance summary

## Suggested success metrics

- learner activation rate
- completion rate by cohort
- average progress by track
- attestation completion rate
- content readiness before publish
- number of at-risk learners detected early

## Implementation workstream

Week 1:

- branding
- access setup
- content import

Week 2-3:

- lesson adaptation
- cohort setup
- reporting validation

Week 4-6:

- live pilot delivery
- admin and manager feedback
- issue remediation

Week 7-8:

- KPI review
- rollout proposal

## Commercial structure

Suggested structure:

- one-time implementation fee
- fixed pilot platform fee
- optional AI activation fee
- optional enterprise identity activation fee

## Conversion path

At the end of the pilot, convert into:

- annual platform agreement
- private deployment contract
- multi-academy rollout
- add-on professional services
