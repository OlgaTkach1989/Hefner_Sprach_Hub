# Security Review Checklist

Use this checklist before sending the platform into enterprise security review.

## Product and deployment

- deployment topology documented
- environment owner identified
- production hostname confirmed
- backup jobs enabled
- restore order documented
- smoke-test command available

## Identity and access

- active login mode confirmed
- identity providers reviewed
- admin accounts reviewed
- scoped accountability reviewed
- customer-facing role model confirmed

## Governance and evidence

- lifecycle states enabled
- publish gates documented
- attestation wording reviewed
- completion evidence behavior validated
- audit events reviewed for governance actions

## Data protection

- retention baseline defined
- deletion expectations defined
- DPA template prepared
- subprocessors list updated
- support and incident contacts defined

## Customer package

- security package attached
- architecture and data flow attached
- access matrix attached
- pilot offer attached
- vendor deck attached
