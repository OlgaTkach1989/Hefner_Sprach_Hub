# Hefner Sprach Hub business card

Open `index.html` to preview and print the compact 85.6 × 54 mm card. Its QR code opens the full course information page at `https://olgatkach1989.github.io/Hefner_Sprach_Hub/angebot/`.

The GitHub Pages workflow copies `landing/` to `/angebot/` as part of the existing site deployment. The QR image is provided by a free QR image endpoint and encodes the landing page URL.

Company prices are not displayed. Confirmed lesson prices can be added to the information page when available; the previous source repository was not accessible from this checkout.
